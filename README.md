# 🏦 Banking & Credit Card Fraud Risk Analytics (SQL & Power BI)

## 📌 Executive Summary
An end-to-end financial data analytics project focused on transaction monitoring, fraud detection patterns, running balance simulations, and customer risk profiling based on enterprise transaction datasets (IBM Financial Data).

## 🛠️ Tech Stack & Methods
* **SQL (Google BigQuery:** Window functions, Common Table Expressions (CTEs), multi-table relational joins, data cleansing, and cohort aggregation.
* **Data Modeling:** Star Schema design connecting Users, Cards, and Transaction fact tables.
* **Business Intelligence (Power BI):** Risk KPI dashboards, anomaly detection, and fraud velocity tracking.
* **Applied Focus:** Banking operations, transaction fraud profiling, credit limits monitoring.
